### Data Structure

It is a way to organize, storing and managing the data in the comuputer memory.

#### Why we need it ? 
It helps to -
  - run the program fast
  - handle the large ammount of information smoothly
  - Use the less memory efficiently

#### How they solve it ?
  - Manage flow : Like Queue (First In First Out) & Stack (Last in First Out)
  - Speed Up Searches : Helps to sorting the data in ascending and descending order for searching.
  - Connect Data : Like Graphs for networks, friendships in social media.

#### What actually they do ? 
It actually does -
   - Preventing  wasting the memory space
   - Organize the data in clear order
